## 3. Правила движка, которые должны жить в экспортёре

Полный список с адресами — в отчётах; ключевое, чего **не проверяет** движок и что даёт краш:

**Скины:** «первый» атомик для движка — ПОСЛЕДНИЙ в файле, он должен быть со скином; костей ≤ 64; `numBones == numNodes`; флаг HAnim без бита 0x2; keyframe size ≥ 28 (ваниль 36); таблица узлов на дочернем фрейме, одна; обязательные id костей 0,1,2,3,4,5,21–24,31–34,41–43,51–53; `maxWeights` 1..4, `numUsedBones ≥ 1`; имена фреймов ≤ 23.

**IFP:** имя блока ≤ 15 и == имени файла; 0 кадров = краш; смешение сжатых/несжатых = порча; ANP3 int16: |смещение| < 32, |q| < 8; ANPK — 44-байтовый ANIM для SA.

**COL:** размер записи ≥ 24 + заголовок (0x4C/0x58/0x5C); счётчик ≠ 0 при смещении 0 — краш; смещения за пределы записи — краш; грани int16 ≤ 32767; координаты ±255.99 (int16/128), plane distance < 256; surface ≤ 178; имя ≤ 21; объект в IPL без коллизии (и не LOD с одним потомком) — краш; пул `CColModel` 10150 (ваниль 9958), **.col-файлов ≤ 255 (ваниль 251)**.

**DFF карты:** чанки ATOMIC ≤ 16, MATERIAL ≤ 28, TEXTURE ≤ 0x110, имя текстуры ≤ 128 байт (в TXD ≤ 31); все индексы (frame, parent, geometry, material, BinMesh, треугольники) в диапазоне; NATIVE-флаг несовместим с `hasVertices`; `numMaterials ≥ 1`; texcoord sets ≤ 8; фрейм `*_dam` только с IDE-флагом 0x1000; 2DFX: типы SA, точные размеры записей, текстура короны/тени должна быть в `particle.txd` (иначе краш); ночные цвета только вместе с PRELIT и по числу вершин; кламп-модель без атомиков — краш.

**TXD:** без PAL4/PAL8; `rasterType` = 4; размер mip-уровня = stride·rows (DXT: ceil(w/4)·ceil(h/4)·8|16); `numLevels ≤ floor(log2(max(w,h)))+1` с MIPMAP и == 1 без; ширина/высота ≠ 0; STRUCT словаря ровно 4 байта; имена ≤ 31; пул 5000 (ваниль ~3990).

**Текстовые данные:** строка ≤ 511; IDE id 0..19999, имена модели/TXD ≤ 23, `objs/tobj` draw distance ≥ 4.0, хранилища 14000/70 damage/169 tobj/92 anim/212 cars/278 peds/51 weap, 2DFX-секция ≤ 100 записей подряд по модели; IPL `inst` ровно 11 полей, lod-индекс валиден, кватернион нормирован, позиции ±3000, ≤ 4096 inst в текстовом IPL; `grge` имя ≤ 7 (иначе краш), `enex` ≤ 31 в кавычках, `auzo` ≤ 7, зоны ≤ 7 символов и ровно 10 полей (380 nav / 39 map); бинарный IPL: int16-счётчики; `nodes*.dat` 0..63; timecyc ровно 184 строки данных, 51/52 колонки, sun/sprite·10 → int8 (≤ 12.7), postfx alpha·2 → uint8 (≤ 127), цвета 0..255; water: ≤ 1021 вершин, 301 квадов, 6 треугольников, целые координаты ±3000, |flow| < 2, прямоугольники по осям, блоки 500; plants.dat 18 токенов, ≤ 57 поверхностей, id 0..177; effects.fxp `NUM_PRIMS ≤ 8`, `NUM_KEYS ≤ 127`, |t| < 128, имена текстур ≤ 31 и должны быть в `effectsPC.txd`.
