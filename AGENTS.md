# INU Check (gtacheck) — памятка для работы над репозиторием

Оффлайн-проверщик папки GTA (SA/VC/III): своё окно на скелете librw + ImGui 1.92.2b и режим `--cli`.
Проходит папку так, как это делает `gta_sa.exe` при старте (gta.dat, IMG, IDE/IPL, DFF/TXD/COL/IFP,
handling/weapon/ped/clothes/cuts/gxt/scm/audio) и выдаёт проблемы с кодами правил, выведенными из
реверса загрузчиков 1.0 US (`docs/re/`). Вынесен из `ariane-support-INU-Tools-and-DragonFF-/tools/gtacheck`
12.09.2026 — та копия больше не источник, работать здесь.

## Правила работы (от пользователя)

- Отвечать **по-русски**; код и идентификаторы как есть.
- **Никогда не запускать GUI** (`inu_check.exe` без аргументов) — окно откроется на его экране. Для
  проверок только `--cli <папка>` (+ `--txt f`, `--no-dff` …) и `--txd-fix in out [--ppm]`; оба входят
  в консольный режим. Запускать через PowerShell `Start-Process -Wait -NoNewWindow` (консольный вывод
  через AttachConsole не ловится редиректом — писать в файл `--txt`/`--lang-missing`/`-RedirectStandardOutput`).
- **Не делать git commit/push/reset/tag** — он коммитит сам; текст коммита можно показать.
- Файлы игры пользователя (`D:\…`) — только читать. Тестовые сборки: `D:\Grand Theft Auto San Andreas`
  (ваниль 1.0 US; после «скрыть ванильное» 0 крашей — 2 DAT-03 это его свой `data/maps/ariane/custom.ide`),
  `D:\FlareMTA\sa`, `D:\GTA Silent Hill`, `D:\GTAclear`, `D:\Grand Theft Auto III`, `D:\Grand Theft Auto Vice City`.
- Маленькая просьба = маленькая правка; не рефакторить соседнее по догадке. Не винить пользователя.
- Патч-скрипты писать **в файл** (Write) и запускать `python file.py` — inline heredoc в Bash ломает
  `\n`, обратные слэши и бэктики. Сборка: `cmd /c ".\build.bat 2>&1"` из PowerShell (1–2 минуты, без вывода).
- UX-стандарт: эвристики Нильсена + progressive disclosure, пояснения в тултипах, главное действие одно.

## Сборка и тесты

- `build.bat` → `bin\win-amd64-d3d9\Release\inu_check.exe` (**с нижним подчёркиванием — так попросил пользователь 13.09**; MSVC x64, /std:c++17 /utf-8, линк с
  `librw\lib\win-amd64-d3d9\Release\rw.lib`). Объектники в `build\`. **Иконка и версия в exe**: `src/gtacheck.rc`
  (`#pragma code_page(65001)`, `1 ICON "gtacheck.ico"` + VERSIONINFO) → `rc.exe` → `build\gtacheck.res` в линк;
  `gtacheck.ico` (16…256) делает `src/gen_icon.py` из **`src/icon.png` — картинка пользователя** (synthwave-силуэт с
  машиной; без неё рисует оранжевую плитку с галочкой); иконка окна — `LoadIcon(instance, MAKEINTRESOURCE(1))` в
  `librw/skeleton/win.cpp` (ещё одна локальная правка форка).
- librw — форк `librw-southland` **с локальными правками** (не в апстриме): `src/d3d/d3d9.cpp` (CreateTexture
  может вернуть NULL — не разыменовывать), `src/d3d/d3ddevice.cpp` (`tryReset()`: проверка HRESULT у
  `Reset()`, `rw::d3d::deviceUsable()/tryResetDevice()/lastResetResult()/requestReset()` в `rwd3d.h`), `src/frame.cpp`,
  `src/clump.cpp` (`Clump::streamRead`: если плагины клампа не прочитались — нет EXTENSION, DFF-02 — апстрим
  проваливался в `failgeo/fail` и освобождал `geometryList`/`frames` второй раз → 0xC0000374; теперь
  `clump->destroy(); return nil`), `skeleton/win.cpp` (`GTACHECK_HIDDEN` — окно не показывается; `customFrame` — окно без системного заголовка для темы «студия»),
  `skeleton/imgui/imgui_impl_rw.cpp` (KEYDOWN/KEYUP шлют и `ImGuiMod_Ctrl/Shift/Alt` — без них в ImGui ≥1.87
  `io.KeyCtrl` всегда false: Ctrl+C/V/X/A, Shift-выделение, Ctrl+F/S не работали). Пересборка rw.lib: `cmd /c` с `vcvars64.bat`, затем
  `msbuild librw\build\librw.vcxproj "/p:Configuration=Release win-amd64-d3d9" /p:Platform=x64 /m:1`
  (с `/m` параллельные cl.exe дерутся за rw.pdb → C1041; зависшие cl.exe добить).
- Дымовой тест: `inu_check.exe --cli "D:\Grand Theft Auto San Andreas" --txt %TEMP%\r.txt` → «Краш 2 …
  скрыто ванильных 1040» (21.09; базис регенерирован 16.09.2026: QLT-15 выключен, сообщение QLT-06 изменилось; было
  531 → 571 → 1036 → 938 → 1040). Путь с пробелами в `-ArgumentList` квотировать явно (`'"D:\…"'`), иначе exe печатает usage. Остальные строки — его `data/maps/ariane/*` (DAT-03 ×4, COL-02, COL-25 ×2). Кодек TXD: `--txd-fix <in> <out>` печатает формат каждой текстуры, `copy: BIT-EXACT`
  для нетронутого файла, применённые правки; `--ppm` кладёт дампы до/после (смотреть через PIL → PNG).
  Ещё ключи CLI: `--html f` (отчёт с пояснениями правил), `--fix-all`, `--undo` (после проверки откатывает последнюю
  запись из журнала `gta_check_backup\undo.txt`; печатает «Откачено: …» / «Откатывать нечего»).
- Тест журнала/отката: `mk_undotest.py <имя.dff> [img]` (scratchpad; в истории) — вынимает DFF из ванильного gta3.img,
  дополняет первый NodeName до 24 байт (DFF-30, исправимо) и кладёт как loose-файл modloader или в VER2 `models\test.img`
  с `data\gta.dat` + `test.ide`; затем `--cli tmp --no-txd --no-col --no-ifp --no-data --fix-all`, `--undo` → архив
  бит-в-бит как был, DFF-30 возвращается.
- **Самотест превью без окна** (единственный разрешённый способ гонять GUI-код): `GTACHECK_HIDDEN=1
  GTACHECK_MVTEST=<модель> inu_check.exe "<папка>"` → после проверки выбирается строка `<модель>.dff`, панель
  «Модель» грузит и рендерит 30 кадров, каждый шаг + `HeapValidate` всех куч → `gta_check_mvtest.txt`
  («done: <err> | <info>»), затем выход. Запускать из `bin\...\Release` (`Start-Process -PassThru`, ini
  пишется туда же). Так найден двойной free в librw на fire_ex.dff (FlareMTA).
- Синтетический тест правил: временная папка с `data/gta.dat` + IDE/IPL (пример: правило LOD, `mk_lodtest.py`
  в истории) и `--cli tmp --no-dff --no-txd --no-col --no-ifp`.


## Актуальные уточнения после сверки с кодом (03.10.2026)

- Основной вид — редактор мира (`editor=1`), заводские предпочтения — `src/ui_defaults.h`. Настройки/положения окон — `inu_check/settings.ini` и `windows.ini` рядом с exe; кэш, набор PreLight и бэкапы — `inu_check/cache.bin`, `bake.txt`, `backup/` в папке игры.
- Лампы/точки выбираются кликом, перемещаются только по G; Ctrl привязывает точку к другой. ЛКМ/Enter подтверждают, ПКМ/Esc отменяют. Точки сплайна создаются только через меню ПКМ; «Ставить точки» удалено. Лампы сплайнов кэшируются, неподвижный свет не пересчитывается каждый кадр.
- Освещение окон вызывается через ПКМ по модели: текстуры, рандом по окнам/рядам, сила/радиус распространения света на поверхности той же модели, сглаживание и плоские участки. Пропущенные окна сохраняют ночные цвета. Дополнительный свет не сглаживает оригинальный prelit.
- `--out` перенаправляет записи IMG, но не loose-файлы. Общий автофикс не перепаковывает выросшие записи IMG; редактор TXD и запекание имеют fallback в `modloader/inu_check_fix` или `inu_check/out`.
- QLT-16 — дневной prelit без ночного набора; `--bake-prelit all` — расставленные objs/tobj без дневного prelit. Автофикс из QLT-16 не подключён. QLT-15 выключен.
- `--dry-run` относится к запеканию/переносу окон, не запрещает записи всех других инструментов. CLI-код выхода отражает краши проверки, а не общую успешность последующих правок.
- Старые датированные записи ниже — история разработки; при расхождении текущие исходники и раздел 13.1 руководства имеют приоритет. Ограничения запуска GUI, записи файлов игры и git-действий остаются прежними.

Проверено: ваниль scumgym1_LAe (день 54 / ночь 22 против ванильных 78 / 18), FlareMTA ggntu_2 без prelit (+14416 байт, librw читает), запись + `--undo` на синтетике (`mk_baketest.py`). **Свои фонари** (просьба 21.09 «искусственно подсвечивать модель нужным цветом, вокруг модели относительно нормалей на заданной высоте»): `BakeRig` → `BakeRigLights(dff, mat, rig, out)` — стены (|n.z| < 0.6) биннятся по азимуту нормали на `sectors`, у каждого сектора со стенами (≥ 0.5 % площади) фонарь = центр стен + нормаль × `dist`, z = низ модели + `height`; без стен — кольцо вокруг bbox. `BakeLight` получил strength/when (день|ночь|оба)/shadow/mode (**светить** = прибавить, **окрашивать** = `col *= 1 − w + w·rgb`, чтобы удвоенный prelit не пересвечивался), `rig`, `local/aim` для отрисовки; 2dfx-лампы = ночь/add/тень, гейт `o.night` только для них. Фонари передаются через `BakeOptions::lights`. Секция «свои фонари вокруг модели» в окне (секторов, отступ, высота, радиус, сила, цвет, когда, режим, с тенью), в превью — ромбы цветом фонаря + линия к стене (`mvDrawBakeLights` из `mvRender`). ## Гочи (набитые шишки)

- **Версия программы** — `GC_VERSION` в `gtacheck.h` (заголовок окна, верхняя полоса, Справка, TXT/HTML-отчёты через
  `withVersion()`, crash-лог, CLI usage) + `FILEVERSION/ProductVersion` в `src/gtacheck.rc` + бейджи в README/README_rus. Поднимать все три.
- Все исходники внутри `namespace gc { }` — новый .cpp без него не видит `T()` и остальное.
- **lang.cpp (21.09)**: `translateInner` выбирает лучший шаблон **из обоих корзин** (по первому байту литерала и «начинается со спецификатора») по длине литеральной части — раньше корзина первого байта побеждала всегда, и короткий «геометрия %d: %s» съедал целые сообщения DFF-24; разбор «a, b» вложенных фрагментов при `at == 0` уходил в **бесконечную рекурсию** (правая часть с разделителем = вся строка) → 0xC0000409 в `--lang en --info` на ванили; теперь `at == 0` пропускается и глубина ≤ 12. Шаблон с `%s` в конце после короткого литерала — опасен: матчит всё.
- `Context::add` считает ключ ванили по **русскому** тексту; сообщения правил пишутся по-русски в check_*.cpp
  и переводятся при показе. Формат без кириллицы с русскими `%s`-аргументами (`%s: %d > %d — %s`) нужен
  вручную одинаковой строкой в lang.tsv.
- IMG: побеждает **первая** зарегистрированная запись с именем; im2D ≤ 10k вершин за вызов; `sscanf` лишние поля ок.
- Катсцены: ванильные IFP имеют убывающие времена/NaN-кватернионы (bcesa4w, bcras1) — для `cutscene=true`
  IFP-07/09/16 понижены. GXT-04: TABL не кратен 12 — WARN (движок съедает (size/12)*12).
- AUD-12: краш только для банков, грузящихся при старте; ленивые — ошибка.
- CUT-07: 550 special-моделей (ms_pExtraObjectsDir) — с limit adjuster INFO.
- DAT-22 LOD: ваниль — 1418/1419 LOD в той же точке (общий LOD рельсов 52 ед.), в модах общий LOD до ~120 → порог 200.
- ImGui 1.92: `InputTextMultiline` строки через `g.FontSize`; `IncludeItemByIndex` для прокрутки к строке;
  `ImGui::Shortcut` с RouteGlobal|RouteOverActive перехватывает клавишу у активного InputText.
- librw d3d9 читает PAL8/D3D8 напрямую → на современном устройстве `CreateTexture(P8)` падает, assert выключен →
  поэтому в librw подаём TXD **после** своего кодека (`mvLoadTxd`), а превью TXD рисуем своим декодом.
- `Raster::createFromImage` → MANAGED pool; камера-текстура → DEFAULT (librw сам пересоздаёт при Reset).
- В `--txd-fix` тестах извлечённые из IMG записи содержат паддинг секторов → «copy: differs» ожидаемо.
